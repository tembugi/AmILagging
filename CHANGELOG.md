## v1.4.2

- If you moved the menu buttons in Edit Mode, the block now stands next to them, on the screen.
- In Edit Mode you can drag the block anywhere, and it stays there. Drag it back next to the menu buttons to put it back on the bar.
- Click it in Edit Mode for its settings: a Size slider, Revert Changes and Reset To Default Position.
- Moving the menu buttons in Edit Mode no longer takes the block along.
- If you moved your action bar away from the menu buttons, it is no longer nudged sideways.
